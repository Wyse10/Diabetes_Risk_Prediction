# 🏥 Diabetes Risk Predictor

An end-to-end Machine Learning prototype and interactive web application designed to assess diabetes risk based on key clinical health metrics. The project leverages a trained **Random Forest Classifier** alongside a modern and intuitive **Streamlit** dashboard, enabling real-time risk predictions and insightful health analytics.

---

## 🚀 Key Features

### 📈 Real-Time Prediction Dashboard

A user-friendly web interface built with **Streamlit**, featuring interactive sliders and input controls for instant diabetes risk assessment.

### 🤖 Robust Machine Learning Pipeline

Developed using **scikit-learn**, incorporating:

* Exploratory Data Analysis (EDA)
* Data preprocessing and cleaning
* Feature scaling with `StandardScaler`
* Model training and evaluation

### ⚖️ Class Imbalance Handling

Implements **SMOTE (Synthetic Minority Over-sampling Technique)** to address dataset imbalance and improve the model's ability to detect diabetes cases effectively.

### 🔍 Explainable Predictions

Provides feature importance analysis, highlighting the most influential health indicators such as:

* Glucose Level
* Body Mass Index (BMI)
* Age

### 🩺 Actionable Health Insights

Returns prediction probabilities, risk classifications, and tailored health recommendations to help users better understand their results.

## 🛠️ Installation & Setup

Follow the steps below to run the application locally.

### 1️⃣ Navigate to the Project Directory

```bash
cd "Path/To/Your/Disease Prediction"
```

### 2️⃣ Create a Virtual Environment

```bash
python -m venv .venv
```

### 3️⃣ Activate the Virtual Environment

**Windows**

```bash
.venv\Scripts\activate
```

**macOS / Linux**

```bash
source .venv/bin/activate
```

### 4️⃣ Install Dependencies

Upgrade pip and install all required packages:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

---

## 🖥️ Usage

Once the virtual environment is activated, launch the Streamlit dashboard with:

```bash
streamlit run app.py
```

The application will open in your default web browser, where you can enter health metrics and receive an instant diabetes risk assessment.
